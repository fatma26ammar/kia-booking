# 🚗 KIA Service Booking Platform

## Overview

The KIA Service Booking Platform is a web-based solution designed to simplify the vehicle maintenance booking process for KIA customers.

The project was first designed and prototyped in Figma with a focus on user experience and streamlined service scheduling. As part of the development phase, the registration module has been implemented and enhanced with OCR technology to automate customer data entry.

## Key Features

### 📅 Service Appointment Booking

* Schedule vehicle maintenance and repair services.
* User-friendly booking workflow.

### 🪪 OCR-Powered Registration

* Scan a vehicle registration card (Carte Grise).
* Automatically extract vehicle and owner information.
* Reduce manual data entry and improve accuracy.

### 🎨 UI/UX Design

* Complete platform prototype designed in Figma.
* Modern and intuitive user interface.
* Responsive and customer-focused experience.
